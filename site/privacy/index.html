Policy / effective 28 August 2026

See exactly what evidence contains.

Attestations contain outcomes and timings. They exclude restored values, command output, user labels, and secrets.

CLI data

The CLI reads the configuration you provide and starts its commands through your platform shell. Those commands keep your account's file and network access. The JSON attestation contains an ID, timestamps, durations, statuses, neutral check ordinals, the tool version, and a SHA-256 configuration fingerprint. It excludes commands, stdout, stderr, user-supplied labels, query results, schema values, and secrets.

Website and local storage

The public website has no analytics or tracking scripts. When you restore an existing Operator Pack, the license token and latest verification verdict stay in this browser's local storage. The website sends that token only to Sociobot's license verification endpoint. The service worker may cache website files for offline use.

Your choices

Clear this site's browser storage to remove the local license and cached verdict. Delete generated attestation files to remove local drill evidence. Review configured commands before running them. For privacy questions, email privacy@sociobot.in.
