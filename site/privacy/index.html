Policy / effective 28 August 2026

Privacy stays on your machine.

Restore Drill Attestor does not collect, transmit, or store backup contents, database values, command output, or usage analytics.

CLI data

The CLI runs locally. It reads the configuration you provide and starts your local commands. Its JSON attestation contains an attestation ID, timestamps, durations, statuses, neutral check ordinals, the tool version, and a SHA-256 configuration fingerprint. It deliberately excludes commands, stdout, stderr, all user-supplied labels, query results, schema values, and secrets.

Website and local storage

The public website has no analytics or tracking scripts. If you purchase or restore the Operator Pack, your license token and its latest verification verdict are stored in your browser's local storage. The website sends the token only to Sociobot's license verification endpoint. Cached website files may be stored by the service worker for offline use.

Payment

Sociobot/Dodo is the merchant of record. Checkout happens on Sociobot's hosted billing service, whose processing and retention terms apply to payment data. This site never receives card details.

Your choices

Clear this site's browser storage to remove the local license and cached verdict. Delete generated attestation files to remove local drill evidence. For privacy questions, email privacy@sociobot.in.
